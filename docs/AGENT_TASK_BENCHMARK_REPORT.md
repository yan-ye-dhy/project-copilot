# PR2 Agent 任务评测基线开发报告

1. **目标与范围。** 新增独立 Agent 合成任务合同基线，供后续工具观察压缩对照。30 场景 / 15 场景族，20 dev 与 10 holdout 按族隔离；覆盖知识、工单、联合查询、条件满足/不满足提案、证据不足和异常。未修改业务代码、生产配置、旧评测或真实数据。

2. **新增文件。** `evals/agent_tasks/` 包含数据加载/冻结校验、实际编译图 runner、离线评分、比较与 CLI；`evals/datasets/agent_tasks_v1/` 保存固定合成场景与指纹；`evals/results/agent-contract-v1-20261107/` 保存本次结果和摘要；`tests/test_agent_task_benchmark.py` 验证分母、事件计数、未知usage、导入和人工标注边界。使用入口见 [README](../evals/agent_tasks/README.md)。

3. **实现内容。** 复用生产 `AgentRunner` 的实际 LangGraph，预设模型返回与纯内存工具明确标为替身。合同评分、故障终态、真实处理函数执行、外部请求和人工事实支持分别计数。导入 recorded 结果只离线评分，不生成 live 请求；同分母/数据/配置/依赖的两次运行可比较观察字符与执行次数。

4. **设计决策。** 不新增依赖和服务。来源身份校验不冒充事实支持，脚本通过不冒充自主决策。缺失 usage / 外部测量保留 null；缺题计入失败。默认运行 dev，所有输出拒绝覆盖；v1 数据集指纹固定。holdout 公开可见，只是场景族隔离，不宣称盲测。

5. **Codex 自动验证。** 2026-11-07，在独立工作区使用按uv.lock建立的隔离dev-only虚拟环境执行：`PYTHONPATH=src:. /tmp/pc-upgrade-dev-venv/bin/python -m pytest -q tests/test_agent_task_benchmark.py tests/test_agent_graph.py tests/test_eval_freeze.py`，116 passed（其中新增20，集合重叠不累加）。实际 CLI `contract --split all`、保存结果离线 `score`、相同摘要 `compare` 均成功。30/30 合同通过；预设故障终态6/30仍保留；62次模型替身调用、40次工具尝试、34次处理函数执行、10次工具错误；模型实际外部请求和真实服务执行均0。累计 ToolMessage 观察9772字符，测量覆盖62/62次模型调用，非token；usage=null。18项带来源回答/提案的事实支持尚未人工标注。旧图/冻结测试通过，旧跟踪文件无diff；未执行真实服务/付费模型/用户手测。

6. **Git 信息。** 本工作区由执行者完成实现和审核，提交/合并由父任务按本次用户授权执行；本报告不预填提交或推送成功。基线运行起点HEAD与实际逐文件代码指纹已在provenance保存。
