# 公开演示安全模型与当前边界

**公开发布尚未获准：公网硬闸继续返回 503，不能通过本地单元测试或 Docker 配置检查代替真实公网验收。** 管理员异步上传代码尚未对公网开放，禁止把尚未核实的代码路径视为可公开使用。

## 身份和权限

浏览器只向同源 `/api/` 发送请求；EdgeOne 函数只转发固定允许的方法和路由，从服务端环境获取隧道地址及共享密钥，不采用浏览器提供的上游地址或 `X-Forwarded-For`。公开后端需要匹配的代理密钥；此密钥证明请求来自受信代理，**不代表用户已登录或拥有业务权限**。登录使用 Argon2id、随机 Session、数据库中保存的 token 摘要、`Secure`/`HttpOnly`/`SameSite=Lax` Cookie；重要写入还需要 Origin 与 CSRF 校验。邀请码默认启用，管理员必须安全初始化，不存在默认密码。

工单、上下文和提案应绑定经服务端认证的用户。普通用户只能查询自己的工单和操作自己的提案；历史无主数据仅管理员可见。Agent 工具必须使用服务端身份和 SQL 条件过滤，不能使用模型或浏览器声明的 user_id。工单创建仍由用户确认，事务、行锁、唯一键和幂等共同保护，知识检索本身不授予写权限。授权隔离必须以真实独立 PostgreSQL 验证并记录结果。

## 资源、失败和秘密

公网代码使用 PostgreSQL 原子预留逻辑任务配额，默认每用户每日 5 次、全站每日 30 次、每用户并发 1 次；登录注册设有短窗限流与密码哈希并发槽。管理员 TXT/Markdown 文件上限为 4 MiB，整个 multipart 上限为 4 MiB + 64 KiB；默认最多 64 个片段、32,000 字符。公开 PDF 上传显式返回 503：压缩 PDF 可能在解析时膨胀，现有片段与字符限制发生在解析之后，须先完成隔离解析的资源安全验收。本机原 PDF 能力保留。单任务默认最多 16 次供应商请求发起，实际部署仍须端到端验证配置生效。发起计数在外呼前持久化，故中断时可能高于供应商实际收到的次数；逻辑请求、供应商请求、失败、返回的 token usage 与真实账单是不同数据，无法确认时应标记未知。禁止对模型或确认请求进行无限自动重试。

上传接收在读取请求体前获取 PostgreSQL 全局会话锁，限定跨进程同时接收一个文件，并设置 30 秒读取超时；断线和超时释放该锁。此限制已经在隔离 PostgreSQL 中测试，代理和公网环境的实际表现仍需验收。

Cloud Function 时长上限为 120 秒；Agent 的既有执行预算可能更长。需要具备用户归属、幂等、状态持久化、失败恢复和权限复核的异步任务后才能完整使用。等待超时或取消协程**不代表**同步线程、GPU 推理或上游模型请求已经终止；未知结果不得自动重试或提前释放并发槽。

已有后台任务代码将捕获到的不确定结果标为 `unknown`，已领取任务不自动重试并继续占用并发槽；进程被强制终止时状态也可能停留在 `running`。上传附件在未领取期间以字节存于隔离 PostgreSQL，领取事务提交后删除附件行；worker 运行时清理默认超过 24 小时仍未领取的任务及附件，停止期间不清理。SIGKILL 可能遗留临时文件，数据库日志或备份也可能保留历史字节。发布前须明确停止期间的保留、清理与异常恢复方式。

任务提交审计不保存问题、文件内容或凭据；数据库限制全站每分钟 60 次、每账户每分钟 10 次，正常审计活动分批清理超过 7 天的记录。无活动时不清理，超限请求仍会产生数据库锁和写入压力，必须在公网开放前完成外层限流和运维复核。该记录仅覆盖进入处理阶段的部分已认证提交，不能作为全部 HTTP 请求的分母。

管理员公开知识库操作必须确保成功清单、Qdrant 与 BM25 快照一致，并在异常或进程中断后可安全恢复；不得展示伪造的删除或检索结果。数据库、Qdrant 和 Phoenix 不暴露公网。日志与导出 Trace 不记录密码、Session token、API Key、代理密钥或私密原文；检查实际 Trace 的字段后才能确认脱敏。

## 发布前检查

1. 本地配置与构建产物不含 `.env`、密钥、数据库文件、用户资料或模型权重。
2. 公网无认证、代理密钥错误、跨用户读取/确认、非管理员上传/删除、伪造转发头均被拒绝。
3. 隔离真实 PostgreSQL 测试覆盖配额并发、事务回滚、重复确认及崩溃后未知结果；真实 Qdrant 测试覆盖资料删除恢复和快照一致性。
4. 真实 EdgeOne → Tunnel 端到端测试覆盖 Cookie、CSRF、代理头、上传边界、超时和异常脱敏；Quick Tunnel 不支持 SSE，不能伪称已验证。
5. 云资源、隧道与网站发布均获得用户明确授权；公开时限制访问范围并准备关闭和恢复路径。

任一关键项未完成即保持硬闸关闭。本文件描述的是设计与验收要求，不是对当前系统已具备上述全部安全能力的证明。
